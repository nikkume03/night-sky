# night-sky
A simple, interactive night-sky website built using only HTML and CSS...!!
Explore a beautiful starry sky, a glowing moon, shooting stars,
and an aurora effect without using....JavaScript.

Night Sky is a beginner-friendly front-end web development project
inspired by the beauty of the vastt night sky.

The goal was to create a peaceful, space-themed website using
basic HTML for structure and CSS for styling, animations,
and visual effects.....no JavaScript because I got no knowledge of that.

Tech Stack
- HTML5: Used to create the website structure, navigation,
  content sections, cards, and expandable facts.
- CSS3: Used for colours, layouts, backgrounds, star effects,
  animations, transitions, and responsive styling.
- CSS Gradients: Used to create the night-sky background,
  glowing moon, and aurora colours.
- CSS Animations: Used for twinkling stars, the floating moon,
  and shooting-star effects.
- HTML Checkbox: Used with CSS to toggle the aurora effect
  without JavaScript.
